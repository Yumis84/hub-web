Как подключить AI-агента

Claude

  1. В Claude откройте Settings → Connectors и выберите добавление пользовательского коннектора.
  2. Название: AI Agent Hub.
  3. MCP server URL: https://enhcnvzzkyvusthfjnci.supabase.co/functions/v1/mcp-gateway/mcp.
  4. Включите Requires sign-in.
  5. Сначала оставьте OAuth Client ID и Secret пустыми — Hub поддерживает автоматическую регистрацию OAuth.
  6. Нажмите Connect. Откроется страница Hub: войдите в свой аккаунт и нажмите Разрешить.

Если Claude после разрешения снова показывает Connect, это известный класс проблем его OAuth callback. Не создавайте повторные подключения. Для ручного OAuth Client ID/Secret обратитесь к администратору Hub.
