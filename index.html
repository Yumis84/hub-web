Подключение AI Agent Hub

  1. Откройте настройки подключений

  2. Добавьте MCP-сервер AI Agent Hub
  3. Подтвердите OAuth-авторизацию

    После добавления сервера войдите в AI Agent Hub и нажмите «Разрешить». Доступ выдаётся только после вашего подтверждения.

Пароли AI-платформы Hub не запрашивает. Автоматическое открытие формы зависит от поддержки выбранного сервиса.

Как подключить AI-агента

Claude

  1. В Claude откройте Settings → Connectors и выберите добавление пользовательского коннектора.
  2. Название: AI Agent Hub.
  3. MCP server URL: https://enhcnvzzkyvusthfjnci.supabase.co/functions/v1/mcp-gateway/mcp.
  4. Включите Requires sign-in.
  5. Сначала оставьте OAuth Client ID и Secret пустыми — Hub поддерживает автоматическую регистрацию OAuth.
  6. Нажмите Connect. Откроется страница Hub: войдите в свой аккаунт и нажмите Разрешить.

Важно для телефона: открывайте личный кабинет и OAuth Hub во внешнем браузере (Chrome/Safari), а не во встроенном браузере приложения. Встроенный WebView может не сохранять web-сессию после обновления страницы.

Если Claude после разрешения снова показывает Connect, не создавайте повторные подключения. Для ручного OAuth Client ID/Secret обратитесь к администратору Hub.
